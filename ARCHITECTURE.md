# MarketAtlas — Product Architecture

## Vision
Centralized discovery for open-source financial research tools: GitHub repos, AI Agent Skills (SKILL.md), MCP servers.

Feel: GitHub Trending + Codex Marketplace + Linear + Vercel. Silicon Valley minimalism, premium dev-tools.

## System Overview
```
┌─────────────┐      ┌──────────────────┐      ┌───────────────┐
│  Next.js 14 │◄────►│  API Routes      │◄────►│  Supabase PG  │
│  (App Router)│     │  /api/*          │      │  repositories │
│  RSC + Client│     │  GitHub proxy    │      │  snapshots    │
└─────────────┘      │  search/sync     │      │  skills/mcp   │
                     └──────────────────┘      └───────────────┘
                              │ GitHub REST (server-only token)
                              ▼
                     ┌──────────────────┐
                     │  Sync Worker     │
                     │  scripts/discover│
                     │  GitHub Actions  │
                     └──────────────────┘
```

- Frontend: Next.js 14 App Router, TypeScript, Tailwind, shadcn/ui patterns, Motion, Lucide.
- Backend: Next.js Route Handlers (server-only). GitHub token never exposed to client.
- DB: Supabase Postgres (free tier). Local dev fallback: `data/cache.json` generated by real GitHub API.
- Hosting: Vercel (free). Automation: GitHub Actions cron.

## Data Flow
1. Discovery: `scripts/discover.ts` runs category queries against GitHub Search API.
2. Normalization: dedupe by `github_id`, normalize owner/name lowercased.
3. Enrichment: fetch repo details, topics, license, languages; detect SKILL.md; detect MCP (package.json / README signals + server metadata).
4. Snapshots: insert into `repository_snapshots` (stars, forks, open_issues at timestamp).
5. API serves: `/api/repositories`, `/api/skills`, `/api/mcp`, `/api/trending`, `/api/search`.
6. Trending = delta(stars) over snapshot window, NOT total stars. Requires ≥2 snapshots.

## Key Decisions
- No mock data in production paths. All stats from GitHub API or DB snapshots. UI distinguishes "unavailable" vs 0.
- Skills: only listed if `SKILL.md` verified at repo root or `skills/` path via Contents API.
- MCP: only listed if evidence: `mcp` in topics, `modelcontextprotocol` dep, README mentions MCP server + config example. Status: official (publisher verified) / community / experimental.
- Trading-permission warning: if README/code mentions `trade`, `order`, `private key` + `mcp`, show warning badge.
- React Bits Pro Typographic Wall: licensed. Integration is optional behind env flag; never commit key. See `components/TypographicWall/README.md`.
